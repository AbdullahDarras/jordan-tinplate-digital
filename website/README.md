# Jordan Tinplate Canning: the website (final integrated build)

Static, bilingual (English / Arabic) multi-page site. **Every page, home and inner, shares the creative experience** that was prototyped in `website-prototype/` (v0.2): one header and footer with the factory's **final vector logo**, a palette derived entirely from PANTONE 294 C (`#002F6C`), Bricolage Grotesque / DM Sans / Readex Pro typography, custom cursor, page transitions, light / dark mode, a 3D **premium navy-and-gold tin** "stage" in the hero, and the full RTL flip for Arabic.

The pages are generated from one data file by a tiny Node script, and the generated output is committed. No framework, no build step on Netlify (`netlify.toml`: `publish = "website"`).

## Run it

```bash
cd website
python3 -m http.server 8000
# open http://localhost:8000/   (language chooser) or http://localhost:8000/en/ and /ar/
```

Serve `website/` as the **root of a domain** (links are root-relative, e.g. `/en/products/`). Google Fonts load from the web; nothing else is external (see "No external JavaScript"). Useful URLs while testing: `/en/?skip` (no entrance); to replay the entrance run `sessionStorage.removeItem('jt-intro')` in the console, or open a new tab.

  assets/js/site.js     classic script: menu, theme, language preference, header behaviour, page transitions
  assets/js/engine/     the creative engine (ES modules): main.js (entrance, scroll, labs, cursor), scene.js (three.js), art.js (procedural tin artwork: the premium logo tin, the industry tins and their gold logo seal; the logo is drawn with Path2D from logo-paths.js), logo-paths.js (generated)
  assets/vendor/        three 0.160.1 (+ RoomEnvironment, RoundedBoxGeometry), GSAP 3.12.5 + ScrollTrigger, Lenis 1.1.13 (versions, licences, SHA-256: vendor/README.md)

  assets/img/gallery/   photos for the gallery (does not exist until the first photo arrives, see "Gallery")
  assets/img/           favicon.svg (the gear mark, generated by tools/logo.mjs), og-default.png (1200x630, generated by tools/screenshots.mjs og)
  tools/content.mjs     ALL copy, English + Arabic side by side: t('English', 'العربية'); section copy for the labs, marquee, seasons, story
  tools/logo.mjs        reads brand/logo/*.svg (the supplied vector logos); inlines them in the pages and writes logo-paths.js + favicon.svg (`node tools/logo.mjs`)
  tools/build.mjs       renders every page, sitemap, robots, chooser, 404

  tools/screenshots.mjs headless-Chromium screenshots at 1440 and 390, and the OG image

## How the pieces fit

- **Text is static HTML in the page's own language** (SEO). There is no in-page language flip: the header language button is a normal link to the equivalent page (`/en/products/` to `/ar/products/`) and remembers the choice. `hreflang`, canonical, Open Graph, JSON-LD and the sitemap are unchanged and validated.
- **Progressive enhancement.** Without JavaScript: all text, links, the full navigation, every lab description (all panes are shown), all five journey steps and an SVG drawing of each tin are visible. With JavaScript but without WebGL, or if a library fails: `html.no-fx` / the SVG fallback keep a complete page, the entrance is removed, nothing stays hidden or scroll-locked (inline 8 s guard + a 14 s entrance watchdog + `releasePage()` on any error).
- **3D stages.** Any element `<div class="stage" data-rig="product" data-pose="hero" data-shape=".." data-theme=".." data-cw="0" data-finish="gloss">` gets its own canvas and its own tin (shapes: `round square rect oval oil oil1 oil4 oil8 oil16 cheese milk coffee paint`; themes: `brand olive eid cheese milk coffee industrial`). Chips with `data-pick="shape|finish|cw" data-target="<pose>"` restyle a stage and show their text pane.
- **Entrance**: home pages only, once per browser session (`sessionStorage` key `jt-intro`; landing on an inner page first also counts as seen), visible Skip button (Enter / Escape also skip), `?skip` and `prefers-reduced-motion` skip it. **Reduced motion** also turns off smooth scrolling, split-text and reveal animations, the marquee and the page-transition curtain.
- **Page transitions**: a five-bar curtain on internal links; the arrival side is pure CSS (it clears itself after 1.5 s even if scripts fail).
- **Request a quote** buttons everywhere open the existing order tool <https://jc-order.netlify.app/> in a new tab (`rel="noopener"`); `mailto:sales@jordantinplate.com` is the secondary option.
- **No external JavaScript**: three.js, GSAP + ScrollTrigger and Lenis are self-hosted under `assets/vendor/`. Only Google Fonts (CSS + font files) come from Google.
- `/prototype/` (the old stand-alone creative preview) is gone from `website/` because the home pages supersede it; `netlify.toml` redirects `/prototype*` to `/en/`. The original lives on in `website-prototype/` (untouched).

## Edit and rebuild

1. Edit `tools/content.mjs` (copy, pages, the `SHOW_PENDING` flag), `tools/build.mjs` (markup) or `assets/css|js`.
2. `node tools/build.mjs` (needs Node 18+; no packages). Set `SITE_URL=https://example.com` (staging only) to change the origin used in canonical / hreflang / sitemap / JSON-LD.
3. `python3 -I tools/validate.py` checks: HTML is well formed, internal links and anchors resolve, hreflang is reciprocal and matches canonical and the sitemap, titles/descriptions are unique, OG tags and JSON-LD exist, language switch targets are correct, plus the creative contract (shared chrome on every page, every stage labelled with an SVG fallback, entrance only on the home pages and with a Skip button, no external script, import map points at `/assets/vendor/`, all engine files exist) and the approved decisions (official names, `@jordantinplate`, order-tool links open in a new tab with `noopener`, certifications shown only as the two certificate images with their names (no table markup, numbers, dates, scope text or ISO / FDA claims, no separate logo files, certificate image files exist with the width / height written in the page), the gallery (both videos as facades with no iframe or YouTube script in the HTML, Facebook card, nav link in header / menu / footer, About video before the story and `SITE.mainVideoId` among `VIDEOS`, no photo section while `PHOTOS` is empty, every listed photo exists with `alt_en` / `alt_ar`, every `<img>` has `alt`), no Saudi branch, olive-oil sizes 1/4/8/16, address), the logo contract (one sprite per page, `<use>` in header and footer, accessible name, `theme-color` `#002F6C`, 1200x630 OG image), the palette (every token from #002F6C, WCAG AA text contrast in light and dark, no leftover old blues) and the pending rule: **it fails if "to be confirmed" / «بانتظار التأكيد» (or any placeholder markup) reaches a generated page while `SHOW_PENDING` is false**, or if a hidden block is missing from `PENDING.md`.
4. Commit the regenerated files.

### Hidden items (`SHOW_PENDING`)

Everything that waits for management (a `tbc` block, a row with `tbc: true`, the proof boxes, the draft notice) is **hidden** while `export const SHOW_PENDING = false` in `tools/content.mjs`: `build.mjs` drops it, a section that only held placeholders disappears with it, and nothing on the site says that something is pending. Nothing was deleted: `PENDING.md` lists each item (page, EN/AR text, what management must supply, where it lives and how to restore it). Setting the flag to `true` and rebuilding brings the dashed placeholders back (with `assets/css/pending.css`) for a layout preview. The old Review-mode button was removed.

## Certifications section

`CERTS` in `tools/content.mjs` (title and two items: `file` base path without extension, real `w` / `h`, `name`, optional `sub`, `alt`). `KINDS.certs` in `build.mjs` renders it; styles are under "certifications" in `site.css`. To replace an image keep the name and **update `w` / `h`** (the validator compares them with the real files).

## Gallery: videos, photos and the lightbox

- **Videos** are one list, `VIDEOS` in `tools/content.mjs`: `{ id: '<YouTube id>', label: t('Factory video 1', 'فيديو المصنع 1') }`. Add, remove or re-order entries and rebuild. The labels are neutral on purpose: nobody on the build side has watched the videos, so no titles were invented. Replace them when management gives the real titles. They are click-to-load **facades**: poster (`https://i.ytimg.com/vi/<id>/hqdefault.jpg`) and a play button; the `youtube-nocookie.com` iframe is created by `site.js` only on click, so no third-party code loads before it. If the thumbnail does not load, the on-brand fallback (gradient, gear mark, play icon) stays. Without JavaScript the play button is a normal link to YouTube, and each video has a visible "Watch on YouTube" link.
- **Main video**: `SITE.mainVideoId` (currently `xozO8TLl6T8`) is the featured video near the top of the About page, with a "More in the gallery" link. Change that one constant (it should be one of the `VIDEOS` ids, which the validator checks).
- **Facebook**: a card on the gallery links to `SITE.social.Facebook` for the longer videos.
- **Photos** are not here yet: **photos and videos are to come from management**. `PHOTOS` in `tools/content.mjs` is empty, and while it is empty the gallery renders nothing for photos (no section, no placeholder). **To add photos:**
  1. Put the files in `website/assets/img/gallery/` (create the folder; use web-sized JPEG or WebP, about 1600 px on the long side, under 300 KB each).
  2. Add one entry per photo to `PHOTOS`: `{ src: '/assets/img/gallery/printing-line.jpg', alt_en: 'The printing line at Jordan Tinplate Canning', alt_ar: 'خط الطباعة في المصنع', w: 1600, h: 1067 }` (`w` / `h` optional).
  3. `node tools/build.mjs` and `python3 -I tools/validate.py` (it checks the file exists and both alt texts are present). The grid, the lightbox and the "Photos" heading appear by themselves.
- **Lightbox** (`site.js`, `<dialog id="lightbox">` emitted on pages that need it): opens from the certificate cards and the photos; Esc, the close button or a click on the backdrop close it, focus is trapped inside and returns to the image that was last shown, arrow keys / buttons / swipe move between images of the same group (reversed in Arabic), page scrolling is locked while it is open. Without JavaScript the image links open the JPEG in a new tab.

## The 3D tins

The default tin (hero, entrance, journey, Finish Lab, Shapes lab, seasons) is a **premium tin**: deep Pantone-294-C navy lacquer, champagne-gold foil (embossed rim, double foil rules, notched frame, beaded rows, fine trellis), the factory logo (gear + wordmark + Arabic line) in gold foil on the body and the gear mark on the lid. Each printed surface is drawn three times from the same code in `art.js` (colour, ORM = roughness and metalness, relief), so the foil is smooth, metallic and raised while the lacquer is glossy; the Finish Lab finishes (gloss, matte, soft touch, rough touch, embossing) change roughness, metalness, clear-coat and which relief variant is used. The four colourway chips keep working (navy and gold, copper and gold, teal and gold, cream and navy); the first is the signature tin. The industry tins (olive oil, sweets / ka'ak, white cheese, milk powder, coffee and tea, industrial) keep their themed colourways and carry the logo as a gold seal and on the lid. No image files: the logo is `Path2D` from `assets/js/engine/logo-paths.js`.
