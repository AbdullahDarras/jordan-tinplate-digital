# Working with this project

## How to present work (the owner's standing preference)

The owner is a visual person. **Every deliverable (content, plans, strategies, calendars, reports, anything) is shown as an interactive HTML page in the factory's visual identity**, never as plain text, Markdown or a Docs document.

- Build the page as `.html`, publish it as an Artifact, and keep the source in the repo (social content goes in `content/social/`).
- Identity: PANTONE 294 C (`#002F6C` on screen) and the navy tints in `website/assets/css/site.css`, amber accent `#d98b14` / `#f4b34c`, champagne gold `#e3c06c` as a highlight, the final logo `brand/logo/logo-horizontal.svg` inlined in white on the navy band, fonts Readex Pro (Arabic) and Bricolage Grotesque (Latin and numbers). Rules in `brand/README.md`.
- Arabic first, right to left. Light and dark mode. Works on a phone.
- **The logo is always white** on dark or navy backgrounds (PANTONE 294 C on light ones), **never gold or yellow**. Gold is for accents and highlights only (owner's rule, 2026-10-31).
- Reply in chat in Arabic (Jordanian dialect is fine), short, with the link.
